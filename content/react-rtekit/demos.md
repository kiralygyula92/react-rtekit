# All demos

Each of these is a complete editor for a situation, rather than one capability at a time. They are the fastest way to see how the pieces fit together — and the playground carries its whole configuration in the URL, so a link is a bug report.

- [Playground](/react-rtekit/demos/playground/) — every prop, live.
- [Theme editor](/react-rtekit/demos/theme-editor/) — every token, live.
- [Comment box](/react-rtekit/demos/comment-box/) — the small case.
- [E-mail composer](/react-rtekit/demos/email-composer/) — merge tags and e-mail-safe output.
- [CMS body field](/react-rtekit/demos/cms-body-field/) — the large case.
- [Legacy parity](/react-rtekit/demos/legacy-parity/) — the editor this replaces, and the bugs that are fixed.
- [Large document](/react-rtekit/demos/large-document/) — what performance looks like.
